## 주석 정책 (동의 확인됨)

> 정본 [docs/comment-policy/comment-policy.md](../docs/comment-policy/comment-policy.md) · 하네스 `scripts/comment/comment-lint.py`

### 쓸 때

적용 구역: 제품 코드 구역의 코드 · 마크업. 구역 밖 하네스는 COMMENT-1만 따른다.

주석은 **코드의 역할과 작동 방식만** 최소로 적는다. 설명하지 않는다.

```
Name : 한글명 · YYMMDD[/YYMMDD][ · point-N]
// Name
```

- **영문명** 검색 키. 같은 블록은 파일 전체에서 같은 이름
- **한글명** 최대 5단어
- **날짜** `YYMMDD`. 수정이 없으면 작성일만
- **닫는 표지 필수.** 중첩 허용

🔴 **금지** — 수치·수식·개수, 설명(서술 어미), 이력(날짜·Phase·결함 번호).
🔵 **허용** — 탭·콘텐츠 등장 순번(`TabCont1` `Carousel2`). 삭제해도 **번호를 당기지 않고 결번을 둔다.**

```
❌  <!-- CardList : 카드 12개 · 260918 -->
❌  <!-- Header : 로고와 내비를 포함하며 스크롤 시 고정됩니다 · 260918 -->
✅  <!-- Header : 헤더 · 260918 -->
```

### 읽을 때

**주석으로 결론을 내지 않는다.** 주석은 어디를 볼지 정하는 재료다.

| 단계 | 근거 | 낼 수 있는 결론 |
|---|---|---|
| L1 | 주석·파일명 | 🔴 **없음.** 위치만 정한다 |
| L2 | `point-N` 항목 | 금지 사유·설계 근거 인용 |
| L3 | 코드 흐름 | 현재 상태·값·분기 조건 |

공용 값(PK·설정·권한 플래그)과 분기 조건은 **L3 필수**다. 설계·검수·검증은 **L3 → L2 → L1** 순으로 본다. 주석을 먼저 읽으면 코드를 그 해석으로 읽게 된다.

🔴 **L3 결론과 주석이 어긋나면 그 자체가 결함이다.** 조용히 넘어가지 않는다.

### 오류 참고

코드에는 `point-N` 만 둔다. 내용은 `docs/comment-policy/points/point-{번호}-{주제어}.md` 한 파일씩.

```bash
python3 scripts/comment/comment-lint.py show point-12    # 그 파일 하나만 읽는다(읽기 전용 역할은 --no-record 추가)
```

🔴 `points/` 를 통째로 열지 않는다. 번호는 순증하고 재사용하지 않는다.

### 검사

```bash
python3 scripts/comment/comment-lint.py scan   <경로>   # 실태
python3 scripts/comment/comment-lint.py lint   <경로>   # 규격 위반
python3 scripts/comment/comment-lint.py points <경로>   # 참조 대조
python3 scripts/comment/comment-lint.py map    <경로>   # 맵 갱신
```

### 우선순위

**동작에 영향이 있는가**로 먼저 가른다. 주석 규격 NOTE-1~6 위반도 같은 기준이다 — 등급은 `docs/SSOT/ROLES/SUB-SSOT/VERIFIER/verification-procedure.md`(VP) §G2 판정 기준 「등급 산출」 표로 매긴다(동작 영향이 없으면 대개 Low).

| 성격 | 예 | 처리 |
|---|---|---|
| **동작** | 빌드 실패·렌더 깨짐·죽은 링크·타입 오류 | **즉시** |
| **NOTE 위반** | NOTE-1~6 규격 위반 (형식·금지 수치·결번·닫는 표지·읽기 3단계·point-N) | **보고하고 그 Task에서 고친다.** 등급은 VP §G2 판정 기준 「등급 산출」 표 — Low면 게이트를 막지 않는다 |
| **그 밖의 글자** | 오탈자·표현 다듬기 | **모아서 한 번에.** 단독으로 턴을 쓰지 않는다 |

🔴 **NOTE-1~6 위반은 보고 대상이다.** 그 밖의 글자 오류는 메모만 하고 이어간다.
🔴 검사가 실패하면 통과시키기 전에 묻는다 — **「이 검사는 무엇을 막으려고 만들어졌나?」** 걸린 것이 그 목적에 해당하지 않으면 검사를 고친다.

> **개정 이력** — 2026-09-21 Phase 9-10 D-3. 종전 문안: 「| **글자** | 주석 문구·이력 서술·개수 표기 | **모아서 한 번에.** 단독으로 턴을 쓰지 않는다 |」 / 「🔴 주석 수정은 **보고 대상이 아니다.** 동작 작업 중에 글자 오류를 발견하면 **메모만 하고 이어간다.**」 — 사용자 「동의 확인됨」 정책이었으나, G2가 NOTE-1~6을 Critical로 인용하는 ① 방향과 반대여서 3자 정합(K-2)을 위해 개정했다.
> 2026-09-26 사용자 결정 D-2 B(등급 판정 개선안 — `docs/reports/260926-phase-10-점검-등급판정-개선안.md`), Phase 10-12 T2에서 반영. 종전 문안: 「단, **주석 규격 NOTE-1~6 위반은 동작 영향과 무관하게 즉시 처리한다** — G2 Critical이기 때문이다.」 / 「| **NOTE 위반** | … | **즉시.** G2 Critical — 남은 채로 게이트를 통과시키지 않는다 |」 — 주석 위반도 영향 × 도달성(VP §G2 「등급 산출」 표)으로 매기기로 했다.

### 관리하지 않는 것

의도 서술의 정확성은 **기계로 확인할 수 없다.** `points/` 로 옮긴 뒤에는 **정확성을 관리하지 않는다.** 틀려도 두고 거기에 시간을 쓰지 않는다.
