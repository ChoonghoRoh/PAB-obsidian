PAB SSOT 번들 가이드

개요

Claude Code Agent Teams 운영 하네스다. Team Lead(메인 세션)가 팀을 구성·조율하고, 팀원 에이전트가 역할별 Charter로 병렬·협업 작업을 수행한다. 모든 작업은 상태 기반 워크플로우로 진행된다.

설치 뒤 첫 단계

  1. /project-config init (또는 PROJECT.md 직접 편집)
  2. /project-config sync
  3. 새 세션 시작 후 /menu로 스킬 카탈로그 확인

설치·업그레이드 절차는 번들 INSTALL.md, 프로젝트 설정은 PROJECT.md를 참조한다.

SSOT

진입점은 docs/SSOT/entrypoint.md다. 세션 시작·복구 시 이 문서부터 읽는다.

폴더

경로내용
CORE/공통 포맷·규칙 인덱스
ROLES/역할별 Charter + 역할 하위 절차(SUB-SSOT)
WORKFLOW/상태 머신·게이트·핸드오프·리팩토링 규정
TEMPLATES/계획·보고 양식

상태 흐름

IDLE → TEAM_SETUP → PLANNING → PLAN_REVIEW(G1) → TASK_SPEC → BUILDING → VERIFYING(G2) → TESTING(G3) → INTEGRATION → E2E → E2E_REPORT → TEAM_SHUTDOWN → DONE
게이트 FAIL 시 REWINDING을 거쳐 PLAN_REVIEW는 PLANNING으로, VERIFYING·TESTING·INTEGRATION·E2E는 BUILDING으로 되돌아간다. BLOCKED는 어느 상태에서든 진입한다.

① Telegram 세팅

  1. PROJECT.md frontmatter의 notify_channel을 telegram으로 설정
  2. 환경변수 PAB_TELEGRAM_BOT_TOKEN 설정(봇 토큰)
  3. 환경변수 PAB_TELEGRAM_CHAT_ID 설정(Chat ID)
  4. /notify-telegram 스킬로 발송 확인

🖥️ 하단 인포창

scripts/statusline.sh가 터미널 하단에 모델·폴더·SSOT 버전·Phase 상태를 표시한다. 기본 상태로는 배선되어 있지 않다 — 쓰려면 .claude/settings.json에 다음을 추가한다.

"statusLine": { "type": "command", "command": "\"$CLAUDE_PROJECT_DIR/scripts/statusline.sh\"" }
