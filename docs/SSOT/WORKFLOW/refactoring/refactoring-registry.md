### 주석 부채

`scripts/comment/comment-lint.py scan <경로>` 분류 수와 `lint <경로>` 위반 수를 기록한다. 「lint 위반」은 그 행의 위반 기준선이다 — COMMENT-2 기준선 판정은 대상 파일이 속한 행과 비교한다(파일 행이 있으면 파일 행). COMMENT-3로 정리한 파일은 파일 행을 새로 두어 「lint 위반 0 · 정리일 · 요청 근거」를 적고, 그 파일이 속한 경로 행은 다시 재어 갱신한다.
