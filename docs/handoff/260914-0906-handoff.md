### 6.2 v4 회원제 전환 — 판단은 끝났고 실행이 막혀 있다

**질문 원형**: *"로컬 vault 을 폐기하고 Prove 로 수집을 일원화하면, 서버(3800X)에 쌓인 vault 을 로컬 Obsidian 앱이 볼 수 있는가?"*

**답**: 앱은 **로컬 폴더만 연다.** 원격 경로를 여는 기능이 없다. 성립하는 것은 *"로컬 사본을 만들어 그걸 여는 것"* 뿐이고 그게 LiveSync다. 지금 흐름은 **정확히 반대**로만 돈다.

```
지금  :  로컬 vault ──LiveSync──▶ CouchDB ──bridge──▶ 서버 미러(파일)
필요  :  서버 파일(Prove가 씀) ──▶ CouchDB ──LiveSync──▶ 로컬 앱
                                 ↑ 이 홉이 막혀 있다 (VDU + bridge 미마운트)
```

**권고안 ⒜ (LiveSync 양방향 편입)** — 회원별 DB + **`pabbridge`가 아닌 전용 계정** → members 루트 마운트 + group 추가 → 로컬 앱 연결.

⚠️ **viewer/editor 는 앱이 아니라 문서 구조로 나눈다.** 앱 단위 읽기전용 설정은 **사용자가 끌 수 있다.** 우리 `/wiki` 규격이 이미 2파일이므로 선이 그어져 있다 — **SOURCE(Prove 전용·R-4 불변) / 요약본(사람 편집 허용)**. 강제는 **경로 기반 VDU**로 가능하다(문서 `_id`가 파일 경로).

🔴 **미검증 — 여기서 UX가 갈린다**: **LiveSync 플러그인이 403(쓰기 거부)을 받으면 어떻게 동작하는지 모른다.** 조용히 무시할 수도, 충돌로 남을 수도, 에러를 뱉을 수도 있다. **회원 DB 1개 파일럿으로 실측해야 한다.** 여기가 가장 큰 미지다.

### 6.3 ⚠️ 로컬 vault 폐기가 건드리는 것

- 로컬에 md 가 안 쌓이면 미러도 안 바뀐다. N-3 `mirror-fresh`는 **mtime 을 실패 조건으로 쓰지 않아** 즉시 오탐은 없다. 다만 Observer 가 `O-5`로 물었던 *"정체와 정지를 구분 못 한다"* 가 심해진다 — **지표가 죽지 않고 의미를 잃는다**
