| | **{REPO}** (이 repo) | **{PARTNER}** |

## 4. 주고받는 방법 (허브 §4 요약)

- **상대 → 나**: 상대 소스는 상대 경로를 **직접 읽기**(읽기전용). 근거는 **경로 + 커밋 해시**로 인용(복사 금지).
- **나 → 상대**: 상대 문서 수정 대신 상대 `docs/interop/<이 저장소 slug>/inbox.md` 에 한 줄 append(same-machine · 다른 머신이면 SendMessage).
- 완료·상태 신호는 실측(build/tsc 0 · git A/M/D). "확인함" 금지.
